RLM – The Future v0.5.0 Patch Notes
IMPORTANT

Major release — 6 new tools, new theme, redesigned UI components, and all missing frames restored.

★ 6 New Tools
16. WiFi Network Scanner
Scans nearby WiFi access points using netsh wlan show networks
Displays SSID, BSSID, signal strength, authentication & encryption
Color-coded output (SSIDs in cyan, signal in green, auth in yellow, BSSIDs in purple)
Show Saved Profiles button lists all stored WiFi configurations
17. Hash Identifier & Cracker
Identify — Detects hash algorithm by length/format (MD5, SHA-1, SHA-256, SHA-512, bcrypt, Unix crypt variants)
Crack — Built-in 40+ word dictionary attack against MD5/SHA-1/SHA-256/SHA-512
Generate — Hash any plaintext into MD5, SHA-1, SHA-256, and SHA-512 simultaneously
Shows detailed analysis: length, hex validation, algorithm probability
18. HTTP Header Analyzer
Sends a HEAD request and displays all response headers
Security Audit — Checks for 6 critical security headers:
Strict-Transport-Security
Content-Security-Policy
X-Frame-Options
X-Content-Type-Options
X-XSS-Protection
Referrer-Policy
Rates security score as EXCELLENT / MODERATE / POOR
19. Whois Lookup
Domain registration data via RDAP protocol
Shows: registrar, creation/expiry dates, nameservers, status codes
Falls back to who.is browser if RDAP unavailable
Auto-strips https:// prefixes from user input
20. SSL Certificate Inspector
Connects to port 443 and pulls the full TLS certificate
Displays: protocol version, cipher suite, cipher bit strength
Shows subject CN/O, issuer CN/O, validity dates, serial number
Lists all Subject Alternative Names (SANs)
Expiry check — Warns if certificate expires within 30 days or is already expired
Calculates remaining valid days
21. Password Generator
Generates cryptographically secure passwords using random.SystemRandom()
Configurable: length (4-128), count (1-20), character sets (upper, lower, digits, symbols)
Shows entropy estimate per password
Strength Tester — Analyzes any password for:
Length score
Character variety (4 categories)
Common password detection
Sequential/repeated character detection
Visual meter bar [████████░░░░]
Rating: CRITICAL → WEAK → MODERATE → STRONG → EXCELLENT
